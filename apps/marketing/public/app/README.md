# App assets (provenance)

Generated by `apps/marketing/scripts/build-sprites.mjs` from the guest app's own map images in
`apps/user/components/reservation/` — the same files `SunbedSelection.tsx` layers for every bed
(status box → perforated sunbed → towel when booked → sunshade on each pair). Do not edit these by
hand; change the app's images and re-run the script, so the marketing page keeps showing exactly
what guests see.
