# Workflow: resume a track

1. Read `index.md`; pick an `active` track (or the one named).
2. Open it and read **Resume here** — the next action + required context. Load that context:
   the named files, linked wiki pages (`[[…]]`), and recent **Log** entries for trajectory.
3. If `worktree:` is set, work there. If the track warrants isolation and has none, create a
   git worktree and record its path/branch in frontmatter.
4. Execute the next step. Then run the **handoff** workflow before you stop — always.
