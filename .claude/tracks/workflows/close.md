# Workflow: close a track

1. Confirm the **Goal** is met — or record why it's being abandoned.
2. Set `status: done` (or `abandoned`); write a final dated **Log** entry.
3. Move its row to **Done / archived** in `index.md`.
4. Promote durable learnings: fold them into the wiki (`.claude/wiki/workflows/ingest.md`)
   and/or a memory file. The track's **Log** is the source material for this.
